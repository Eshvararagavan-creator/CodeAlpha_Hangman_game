# CodeAlpha Hangman Game

A simple text-based Hangman game created for the CodeAlpha Python Programming Internship.

## Features

- Five predefined words
- Six incorrect guesses allowed
- Input validation and duplicate-guess handling
- Console-only gameplay with no external dependencies

## Run

```bash
python hangman.py
```

## Test

```bash
python -m unittest discover -s tests -v
```
